How playlists work

Your playlists are yours. Each person who signs in has their own playlists, home rows and lists; they are private Jellyfin playlists on your account. Switching one on, or creating or changing one, updates Jellyfin right away, and every night’s sync refreshes what is in them.

Ready-made playlists come from the library: Recently Added Movies and TV, Downloaded Movies and TV, one per IPTV source (such as “Netflix Movies”), one per list you follow under Discover → My Lists (only what is in the library), and My Downloads (everything you asked Radarr or Sonarr for).

Your own playlists (+ Create) pick titles by genre, rating and year from the whole Jellyfin library, by IPTV source, or both: “Netflix comedies rated 7 or more”. Each playlist has its own order (newest, A–Z, rating, recently added, random).

Every recording gets a picture in Jellyfin within a minute or two of starting, so recordings look the same everywhere: a card with both teams for a game, the show’s or film’s picture, the guide’s, a frame from the recording, or a card with the title. Pictures someone set themselves are never replaced. Switching this off removes only the pictures Tentacle added.

    Install the Jellyfin Plugin

    The Tentacle plugin adds a custom home screen and discover tab to Jellyfin. It's optional but recommended.

    Tentacle can add them to Radarr/Sonarr with the folders as they are (nothing downloaded, moved or renamed). See them in Library →
    How to install:
    1. Open Jellyfin Dashboard → Plugins → Repositories
    2. Click + to add a new repository
    3. Paste the manifest URL below and name it Tentacle
    4. Go to Catalog, find Tentacle, click Install
    5. Restart Jellyfin to activate the plugin
    Plugin Manifest URL
    After installing, go to Jellyfin → Plugins → Tentacle → Settings and set the Tentacle URL to this server's address. Jellyfin then keeps the plugin up to date from this catalogue by itself (Scheduled tasks → Update Plugins, daily); a new version runs after Jellyfin restarts. Settings → About shows which versions run.
