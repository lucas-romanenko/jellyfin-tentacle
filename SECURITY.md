# Security

Please report a vulnerability privately, not in a public issue:
**[Report a vulnerability](https://github.com/lucas-romanenko/jellyfin-tentacle/security/advisories/new)**
(the repository's Security tab, private vulnerability reporting).

Include what is affected (the Tentacle server, its dashboard or the Jellyfin plugin), the version or commit, how to
reproduce it, and the impact. A failing test or a proposed fix is welcome.

Fixes go into the default branch and ship in the next release; only the
latest release is supported.
